기상특보 알림

기상특보가 발효되면 이 앱을 열어 두는 동안 주기적으로 확인해 알려드립니다. iOS는 Safari에서 “홈 화면에 추가” 로 설치한 앱만 알림 권한을 허용합니다.

데이터 제공처

AccuWeather 또는 기상청 API 키는 서버의 .env 파일에 설정합니다 (프론트엔드에는 키가 저장되지 않습니다). 자세한 방법은 README를 참고하세요.

홈 화면에 추가하기 (iPhone)

  1. Safari로 이 페이지를 엽니다
  2. 하단 공유 버튼 ⬆️ 를 탭합니다
  3. “홈 화면에 추가”를 선택합니다
  4. 홈 화면 아이콘으로 앱처럼 실행됩니다
